# Contact Book Manager

About the Project

Contact Book Manager is a simple Python-based application that allows users to manage their contacts. Users can add, view, search, update, and delete contacts through a menu-driven interface.

The application stores contact information in a JSON file, so saved contacts remain available after the program is closed.

# Features

- Add new contacts
- View all saved contacts
- Search contacts by name
- Update existing phone numbers
- Delete contacts
- Save contact data automatically
- Handle invalid menu choices
- Store data using JSON file handling

# Technologies Used

- Python
- JSON
- File Handling
- Dictionaries
- Functions

# Requirements

- Python 3.x
- No external libraries required

# How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Run the Python file:

python ContactBookManager.py

4. Select an option from the menu.
5. Add and manage your contacts.

# Menu Options

Option| Description
1| Add Contact
2| View All Contacts
3| Search Contact
4| Update Contact
5| Delete Contact
6| Exit

# Data Storage

Contacts are stored locally in "contacts.json" using JSON format. This allows the program to load saved contacts whenever it starts.

Keep the JSON file in the same folder as the Python program to access previously saved contacts.
